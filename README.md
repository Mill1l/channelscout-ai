**Evidence-led overseas channel development portfolio — Chile case study.** Research public companies, review evidence, assess channel fit, prepare bilingual outreach drafts and track human-led follow-up. Built with Next.js, TypeScript and Tailwind CSS; local-first, Mock by default.

面向中国制造业海外销售的渠道研究与开发学习作品：把“找公司名单”推进为 **核验证据 → 评估渠道资格 → 区分品牌冲突 → 准备西语沟通 → 记录下一步任务**。以智利、PUDU CC1 Pro / MT1 为业务背景。

**独立学习项目，不是普渡官方系统，不代表厂家授权、真实经销合作或商业落地。默认 Mock / 本地模板，不发送邮件，不需要 API Key。真实 DeepSeek 模型能力尚未验收。**

## 海外销售价值

海外渠道开发的难点不仅是找到公司，还要判断其业务和客户是否匹配、能否部署与售后、是否存在品牌冲突，以及下一次接触前究竟还缺什么证据。本项目把这些判断整理成可追溯的工作流程，避免把“高分”“生成邮件”或“企业自述”误当成合作意愿、真实触达或厂家授权。

这是一项业务方法与产品实现作品，展示渠道研究、资格判断、西语沟通和跟进纪律；没有宣称实现销售收入、签约代理商、真实客户回复或节约多少工时。

## 三分钟演示

启动后打开 http://127.0.0.1:3100/outreach ，选择“隔离模拟演示”并点击“初始化三个模拟案例”。

1. **Proasin（约60秒）**：展开产品与服务来源，说明未知不等于零分、评分覆盖率不等于合作概率；查看具体产品/HORECA切入点，切换西语、编辑并保存草稿。生成不是发送。
2. **Hoppe（约40秒）**：查看Keenon竞争关系和品类/地区/排他条款待核实事项；不因竞品自动拒绝，也不虚构合作意愿。
3. **Dimacofi（约30秒）**：现有渠道仅关系维护；企业公开宣称不等于品牌方独立授权，不重复当新潜客。
4. **跟进（约50秒）**：记录调查任务与日期、查看模拟历史；说明联系/回复须人工声明和沟通摘要。展示旧资料导致旧稿失效及测试结果。

初始化包含**模拟审核、评分、联系和回复**，不是实际企业沟通；单独存于 `.local/phase3-demo/`，不写主工作区。未审核的主资料不会直接解锁邀约；演示源于历史短引文，不是本次实时官网核验。

## 安装与启动

推荐并实际验证：**Node.js 24.11.0、pnpm 12.16.1**。Node最低要求20.9，但其他操作系统/Node组合尚未实机验证。先安装Node，再准备固定包管理器：

```sh
npm install --global pnpm@12.16.1
# 克隆用户最终批准发布的仓库后，进入项目目录
pnpm install --frozen-lockfile
pnpm test
pnpm lint
pnpm typecheck
pnpm build
pnpm start
```

开发模式：`pnpm dev`。应用仅监听127.0.0.1:3100，无登录，不适合直接公网部署。不要复制任何旧node_modules、.next或机器专用运行时。锁文件包含包管理器自管理依赖段及应用依赖段；不要手工截掉其中任一段。

## 功能与数据边界

- 七家真实企业、15条原始公开来源；官网/离线正文研究、事实/推断/未知区分、逐项人工审核。
- 六维评分25/20/20/15/10/10，null不补0；分数、证据覆盖和事实完整度分开。分数不是合作概率、采购意愿或成交率。
- 策略与英西长短邮件草稿：来源可展开、编辑/复制/保存、人工确认、资料版本失效。当前为**有限规则提取/固定模板**，并非已验证的生成式AI个性化。
- 轻量跟进：八阶段、任务/日期/渠道/摘要、优先级筛选和JSON/CSV导出；没有自动发信、实际邮箱送达验证、自动提醒或团队CRM。
- 真实数据：企业官网公开信息及带日期的来源，不保证至今未变化。模拟数据：演示审核与沟通，不能写成真实销售成果。AI/模板建议：需验证的商业推断。人工核验：本机操作者逐项声明，不等于第三方尽调或厂家确认。

## Mock与可选DeepSeek配置

默认无需任何环境文件即用Mock；档案演示完全离线。实时研究读取用户指定的公开网页，最多3页，不爬站或绕过访问限制。

需要配置时将 `.env.example` 复制为 `.env.local`，后者不应提交。默认保持 `RESEARCH_PROVIDER=mock`、`ALLOW_PAID_AI=false`。

真实研究API可选服务端变量：`DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`。只有服务端显式选择deepseek、付费开关、Key及当次人工确认齐备才可能发请求；**真实 DeepSeek API 尚未完成系统性评测，本次发布准备没有执行付费调用。** Key不得使用NEXT_PUBLIC前缀，不放聊天、URL或报告。策略/邮件仍是本地模板。

缺usage显示Unknown，不假定免费；金额需供应商账单核对。45秒、24000字符输入、2200输出tokens、无自动重试；进程内限流不是账单硬预算。真正执行前另行授权次数/金额，冻结脱敏输入与人工标准；失败即停。

## 保存、备份与限制

默认 `.local/workspace.json` 保存研究，`.local/outreach.json` 保存开发记录；可用 `CHANNELSCOUT_DATA_DIR` 设置**私有**目录，不能提交。正常刷新/同目录重启恢复已保存数据，未保存编辑不作保证。备份必须停止服务，详见 [本地保存与恢复](docs/PERSISTENCE.md)。导出不是完整备份。

本机单用户JSON仅单进程串行/原子写入，无跨进程锁或跨文件事务；不能当企业级生产存储。来源90天以上或读取失败需重新核验；HTML大小/时间限制、动态JS/PDF覆盖有限。引文匹配不能证明语义，自动脱敏不是完整DLP，人工编辑仍需自己复核。联系阶段只是人工记录，不证明真实送达。
