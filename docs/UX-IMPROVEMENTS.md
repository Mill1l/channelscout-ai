# 新手与面试演示体验改进

日期：2026-11-05（Asia/Shanghai）

## 解决的问题

原首页重复介绍，功能名称偏技术化，视觉层级和功能颜色接近，进入工作台后缺乏下一步指引。本次只调整呈现与导航，不改变评分、资格门槛、企业事实或证据核验规则。

## 改进

- 首页直接说明目标用户、业务问题和交付物，合并重复介绍。
- 四步导航：蓝色找企业、青绿核验证据、紫色判断渠道、橙色准备跟进；颜色配文字和数字。
- 三个独立模拟案例入口，初始化仍使用既有隔离机制与接口。
- 研究表单增加练习说明，企业档案增加阅读顺序；每个页面显示本页任务。
- 策略、邮件、跟进以三个顺序页签连接，禁用按钮仍遵守原资格和版本规则。
- 证据仅保留一处展开入口，减少重复内容；未知、模拟、人工审核、非官方边界保持可见。
- 提升正文和表单字号、对比度、手机布局、键盘焦点及主内容跳转。
- README 明确在线入口与本机地址的区别，提供三分钟操作路线。

## 数据与发布边界

无新增付费模型调用、无邮件发送、无真实联系记录；原七家企业、15 条来源与六维权重保持不变。在线版仍是访客浏览器独立存储、档案/离线正文与本地模板；不开放实时抓取。
